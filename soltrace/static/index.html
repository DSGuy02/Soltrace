Interactive Showcase · Live on Solana

Know instantly if a business record was changed.

SolTrace saves a fingerprint of each invoice, stock count or order on the Solana blockchain. Anyone can later compare the record with that fingerprint. If even one character changed, it shows.

1

Seal the original

The business approves this record and saves its fingerprint on Solana.

2

Someone edits the database

An insider or attacker changes the record directly in the database. The app itself doesn't notice.

3

Check against Solana

SolTrace recalculates the record's fingerprint and compares it with the one stored on-chain.

Run it yourself

            
Everything here runs on your own machine. No account or wallet is needed: SolTrace uses a built-in local Solana simulator (LiteSVM) by default, or Solana Devnet if you configure it.

          

        


        
    
          
  1. 
            
    Get the code
    
            
    
              
    Terminal
    
              
    git clone https://github.com/DSGuy02/Soltrace.git
cd Soltrace
    
            
    
          
    2. 
          
  2. 
            
    Install dependencies
    
            
    Needs Python 3.10 or newer.
    
            
    
              
    Terminal
    
              
    python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
    
            
    
          
    3. 
          
  3. 
            
    Start this dashboard
    
            
    Then open http://localhost:8000/dashboard and follow the three steps in the Demo tab.
    
            
    
              
    Terminal
    
              
    ./bin/soltrace serve --port 8000
    
            
    
          
    4. 
          
  4. 
            
    Or run the demos in the terminal
    
            
    
              
    Terminal
    
              
    ./bin/soltrace demo invoice
./bin/soltrace demo inventory
./bin/soltrace demo all
    
            
    
          
    5. 
          
  5. 
            
    Connect your own software
    
            
    Send records to POST /api/v1/anchor to seal them and POST /api/v1/verify to check them. Every endpoint can be tried from the interactive API docs.
    
          
    6. 
          
  6. 
            
    Run the tests
    
            
    
              
    Terminal
    
              
    .venv/bin/pytest tests
    
            
    
          
    7.
